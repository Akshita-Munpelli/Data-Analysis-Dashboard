# DMart Sales & Customer Analytics Dashboard
## Project Objective
The objective of this project is to analyze DMart sales, customer behavior, product performance, and profitability using Excel. The dashboard helps identify sales trends, top-performing products, customer insights, and profit patterns to support better business decision-making.
## Dataset Used
The dataset contains retail transaction data related to DMart, including information about products, categories, customers, sales, quantities, discounts, revenue, and profit. The dataset is used to analyze sales performance, product trends, customer behavior, and profitability through an Excel dashboard.
- <a href="https://github.com/Akshita-Munpelli/Data-Analysis-Dashboard/blob/main/Dataset_Dmart.xlsx"> Dataset </a>
## Questions(KPIs)
- What is the Total Sales generated?
- What is the Total Profit earned?
- How many Total Orders were placed?
- What is the Total Quantity of products sold?
- What is the Average Order Value (AOV)?
- How many Customers made purchases?
- What is the Profit Margin (%)?
- Which Product Category generated the highest sales?
